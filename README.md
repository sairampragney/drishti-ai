\# DrishtiAI



\## Explainable Computer-Vision Prototype for Diabetic Retinopathy Screening in Rural India



DrishtiAI is an academic prototype demonstrating a simple doctor-facing workflow for diabetic retinopathy screening.



The project uses browser-based computer vision to detect an eye and demonstrates result presentation using a provided prototype retinal-image dataset.



\## Important



DrishtiAI is NOT a clinical diagnostic system.



The prototype does not provide medically validated diagnoses.



Results are based on prototype dataset information and are intended for demonstration and academic evaluation only.



\---



\# Features



\- Doctor authentication

\- Patient management

\- Camera-based eye detection

\- Computer vision feedback

\- Prototype dataset result selection

\- Screening result visualization

\- Screening history

\- Glassmorphism medical UI

\- Responsive design
